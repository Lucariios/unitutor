# UniTutor

Веб-платформа для пошуку репетиторів серед студентів університетів. Учні шукають репетитора за предметом, університетом, ціною та рейтингом і надсилають заявку на заняття, а студенти створюють анкети й заробляють на власних знаннях. В основі — навчання за принципом «рівний — рівному» (peer-to-peer).

Навчальний проєкт з дисципліни «Веб-орієнтована розробка програмного забезпечення», лабораторна робота №2 «Створення структури веб-проєкту». Концепцію, брендбук і карту сайту описано в лабораторній роботі №1. Поточна версія містить структуру сайту: сторінки, вміст і зображення. Оформлення CSS буде додано в лабораторній роботі №3.

## Структура проєкту

```
unitutor/
├── index.html           # Головна: пошук, популярні предмети, переваги, топ-репетитори, відгуки, FAQ
├── tutors.html          # Каталог репетиторів із фільтрами
├── tutor-profile.html   # Профіль репетитора (приклад) і форма заявки на заняття
├── become-tutor.html    # Стати репетитором: калькулятор заробітку, кроки, правила оплати
├── about.html           # Про платформу: місія, цифри, цілі, аудиторія
├── contacts.html        # Контакти та форма звернення до підтримки
├── login.html           # Вхід і відновлення пароля
├── register.html        # Реєстрація з вибором сценарію: навчатися чи викладати
├── privacy.html         # Політика конфіденційності
├── css/
│   └── style.css        # Таблиця стилів (оформлення буде додано в ЛР3)
├── js/
│   └── main.js          # Скрипти (буде додано на наступних етапах)
├── images/
│   ├── logo.svg, logo-inverse.svg, favicon.svg, apple-touch-icon.png
│   ├── hero-*.webp, about-peer-learning-*.webp   # ілюстрації (560 і 1120 px)
│   ├── icons/           # SVG-іконки предметів і контактів
│   ├── tutors/          # аватари репетиторів (WebP)
│   └── reviewers/       # аватари авторів відгуків (WebP)
└── README.md
```

## Перегляд

Відкрийте `index.html` у браузері: збирання та сервер не потрібні.

## Технології

- HTML5 із семантичними елементами `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`.
- Усі сторінки пройшли перевірку W3C Nu Html Checker без помилок і попереджень.
- Зображення оптимізовано: WebP потрібного розміру, `srcset`, атрибути `width`/`height`, `loading="lazy"`.
- Форми мають вбудовану HTML5-валідацію; надсилання даних з’явиться разом із серверною частиною.
- Аватари: стиль «Notionists» (автор Zoish) із бібліотеки DiceBear, ліцензія CC0 1.0.
